# APON Foundation

Files:
- index.html: page content and structure
- style.css: responsive dark theme with bright green accents, based on the supplied portfolio design direction
- script.js: mobile navigation, active section tracking, scroll reveal, impact counters, and email-preparing contact form
- original-theme-style.css.txt: original supplied stylesheet kept as a reference

How to preview:
1. Keep all files in the same folder.
2. Open index.html in a modern browser, or use a local development server.

Notes:
- Text and impact figures are based on APON Foundation's official website, especially https://aponfoundation.org/what-we-do/.
- Impact figures are labeled as reported achievements and are not independently verified here.
- The contact form does not submit to a server; it opens the visitor's default email app addressed to info@aponfoundation.org.
- The social links currently point to the platforms generally. Replace them with APON Foundation's exact profile URLs after confirming those URLs.
- This is a static front-end concept, not connected to a CMS, donation processor, or backend.
